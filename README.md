# AICT Cloud Assignment 2

## Project Purpose
This project demonstrates basic Python operations on a list of numerical readings. It calculates and displays the number of readings, the minimum value, the maximum value, and the average.

## Readings
The readings used in this assignment are:

[22, 24, 26, 28, 30]

## Expected Output

Count: 5
Minimum: 22
Maximum: 30
Average: 26.0

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command.

   python assignment2.py

No additional Python packages are required.
